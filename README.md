# 🚀 Run Locally

Clone the repository

```bash
git clone https://github.com/Abhirishitha/Portfolio.git
```

Navigate into the project

```bash
cd Portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

The application will be available at

```
http://localhost:3000
```
